# Data

## Included file
`sample_synthetic_jobs.csv` - **SYNTHETIC** (600 rows). Generated by `src/data_loader.py::generate_synthetic_dataset(seed=42)`.
It is **not** real job-market data and must never be cited as evidence of real demand or salaries.
Every row carries `data_source = "SYNTHETIC (generated, not real market data)"`.

## Using a real dataset (recommended for your final demo)
1. Download a public job-postings CSV (e.g. from Kaggle, Hugging Face Datasets or a government open-data portal).
   **Check its licence and attribution requirements yourself** - this repo does not bundle third-party data.
2. Upload it on the *Dataset & Data Quality* page. Columns are auto-detected (title, description, skills, location, salary, date);
   fix the mapping manually if needed.
3. Record the dataset name, URL, licence, download date and row count in the table below and in `docs/project_report.md`.

| Field | Value |
|---|---|
| Dataset name | _fill in_ |
| Source URL | _fill in_ |
| Licence / terms | _fill in_ |
| Date downloaded | _fill in_ |
| Rows / columns | _fill in_ |

Minimum useful columns: a job title and (description or skills). Salary, location and date are optional.
